# 🔥 GeyserEvent — Ивент «Адский Разлом (Вторжение Босса)» (Purpur 26.2)

Плагин на босс-ивент **«Адский Разлом»** для анархии на ядре **Purpur 26.2**, созданный специально с поддержкой **только для игроков Bedrock Edition (GeyserMC / Floodgate)** и выдачей донат-валюты (**осколков**) через **PlayerPoints**.

---

## ✨ Основные возможности

1. **Только для Bedrock Edition (GeyserMC + Cumulus UI)**
   - Проверка игроков через `GeyserApi.api().isBedrockPlayer(uuid)` и `FloodgateApi`.
   - Если включён режим `bedrock.strict-only: true`, наносить урон боссу, участвовать в ивенте, получать награды и открывать меню могут **только игроки с Bedrock** (администраторы с правом `geyserevent.bypass.bedrock` могут тестировать и с Java).
   - Нативные окна **Cumulus (`SimpleForm` и `CustomForm`)** вместо сундучных меню — адаптированы под экраны телефонов и геймпады.
   - Мобильный навигатор в **ActionBar** со стрелкой направления (`⬆ 142м`) и **BossBar** с живым ХП и координатами.

2. **Собственная схематика «Адский Разлом» (без телепортации в Ад!)**
   - Встроенная схематика `plugins/GeyserEvent/schematics/infernal_rift.schem.yml`: кратер из чернита, позолоченного чернита, магмы, плачущего обсидиана, колонн с огнём душ и врат из `NETHER_PORTAL`.
   - Полотно портала ставится с `applyPhysics = false` (не рассыпается) и защищено слушателями `PlayerPortalEvent` и `EntityPortalEvent` — **портал никогда не телепортирует игроков или мобов в Незер**.
   - **Полный авто-откат ландшафта**: после окончания ивента (или перезагрузки сервера) все блоки схематики автоматически возвращаются в исходное состояние.
   - Возможность сохранить собственную постройку прямо из игры: `/rift saveschem <радиус>`.

3. **Мир появления**
   - По умолчанию ивент появляется на случайных безопасных координатах в мире **`world2`**.
   - Мир можно изменить в любой момент в `config.yml` (`event.world: "world2"`), через команду `/rift setworld <мир>` или через админ-меню Bedrock (`CustomForm`).

4. **Босс — Большой Брутальный Пиглин (2 метра)**
   - **Моб**: `PIGLIN_BRUTE` с отключённой зомбификацией (`setImmuneToZombification(true)` — не превращается в зомби-пиглина в обычном мире `world2`).
   - **Размер**: Увеличенный масштаб (`Attribute.SCALE`, 2+ метра ростом).
   - **Оружие**: Зачарованный **Незеритовый топор** (`NETHERITE_AXE`).
   - **Здоровье**: **`3500` HP** (работает даже на серверах со стандартным лимитом `2048` в `spigot.yml` за счёт синхронизированного пула здоровья).
   - **Урон**: **`15` единиц** за удар.

5. **Способности Босса (в радиусе 15 блоков от босса)**
   - **⚡ Притягивание (`pull`)**: Огненными цепями притягивает всех игроков в радиусе 15 блоков прямо к боссу и накладывает замедление.
   - **💥 Отталкивание (`push`)**: Бьёт Незеритовым топором о землю, создавая взрывное кольцо и отбрасывая всех игроков в радиусе 15 блоков.
   - **🌀 Собрать всех в одно место (`gather`)**: Создаёт гравитационную воронку перед собой и **стягивает всех игроков в радиусе 15 блоков в одну общую точку** прямо перед топором босса!
   - **🔥 Призыв приспешников (`minions`)**: Раз в 25 секунд (настраивается) призывает свиту вооружённых приспешников из портала Разлома.

6. **Награды по урону через PlayerPoints (Осколки)**
   - Ведётся точный подсчёт урона каждого игрока по боссу:
     - 🥇 **1 место** — **`3000` осколков**
     - 🥈 **2 место** — **`2000` осколков**
     - 🥉 **3 место** — **`1000` осколков**
   - Выдача происходит автоматически через `PlayerPointsAPI.give(uuid, amount)` (с резервной поддержкой консольной команды `points give %player% %amount%`).

## 🎮 Команды и Права

| Команда | Описание | Право |
|---|---|---|
| `/rift` (или `/event`, `/razlom`) | Открыть нативное меню Bedrock (Cumulus SimpleForm) | `geyserevent.use` (по умолч. всем) |
| `/rift top` | Открыть таблицу топ-урона и наград (3000/2000/1000 осколков) | `geyserevent.use` |
| `/rift compass` | Включить/выключить стрелку-навигатор до Разлома в ActionBar | `geyserevent.use` |
| `/rift info` | Описание характеристик и способностей Босса | `geyserevent.use` |
| `/rift admin` | Открыть админ-панель в нативной форме Bedrock | `geyserevent.admin` |
| `/rift start` | Запустить ивент на случайных координатах в мире `world2` | `geyserevent.admin` |
| `/rift start-here` | Запустить ивент прямо на текущей позиции администратора | `geyserevent.admin` |
| `/rift stop` | Остановить активный ивент и откатить схематику | `geyserevent.admin` |
| `/rift ability <pull\|push\|gather\|minions>` | Принудительно активировать способность Босса | `geyserevent.admin` |
| `/rift setworld <мир>` | Изменить мир появления ивента и сохранить в `config.yml` | `geyserevent.admin` |
| `/rift saveschem <радиус>` | Сохранить постройку вокруг себя как схематику Разлома | `geyserevent.admin` |
| `/rift reload` | Перезагрузить `config.yml` и файл схематики | `geyserevent.admin` |

## 🛠 Сборка проекта

### С помощью Maven:
```bash
mvn clean package
```
Готовый файл плагина появится в `target/GeyserEvent-1.0.0.jar`.

### С помощью Gradle:
```bash
./gradlew build
```
Готовый файл плагина появится в `build/libs/GeyserEvent-1.0.0.jar`.
