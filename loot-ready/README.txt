# Готовый лут GeyserEvent

Скопируй нужную секцию в plugins/GeyserEvent/config.yml
(замени соответствующий кусок: excavation.brushes / cauldron.reagents /
mine.geodes / minions.loot / alien.chests.loot / wind.loot / skibidi.loot / ronaldo.loot).

Легендарка: незерка и алмазка Защита 4, мечи Острота 5, кирки Удача 3.

Чары (enchants: protection: 4) работают с плагином v1.21.27+ (Роналду — v1.21.29+).
Старый jar поле enchants игнорирует — броня будет без чар.
