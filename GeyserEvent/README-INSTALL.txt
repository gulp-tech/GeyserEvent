Как поставить эту папку (jar уже новый)

Скопируй ВНУТРЬ plugins/GeyserEvent/ :
  config.yml
  deluxemenus/events.yml
  schematics/*  (все схемы, включая ronaldo_stadium.schem.yml)
  GeyserEvent-Pack.mcpack
  resourcepack/GeyserEvent-Pack.mcpack

НЕ удаляй всю папку — оставь backpacks.yml если игроки уже фармили шахту.
НЕ затирай mine_terrain_backup.yml если шахта уже построена.

Лут раскопок / котла / шахты / пришельцев — твой с сервера.
Роналду, шкибиди, клад — новые. Кирка легендарка: Удача 3.

Bedrock: перезайди в игру (пак 1.21.17).
